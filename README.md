# 🎁 준우 · 정우 생일 AR 서프라이즈

유리 선물 그림(흰 테두리 선 + 투명 유리)을 휴대폰 카메라로 비추면, 그림 위로 **진짜 선물(3D)** 이 튀어나오는 웹 앱입니다.

| 아이 | 선물 | 연출 |
|---|---|---|
| 준우 | 하프물범 필통 | 복슬복슬한 털, 지느러미를 저으며 그림 위를 빙글빙글 헤엄, 공기방울 |
| 정우 | 스타 스파크 검 | 광택 있는 금속 손잡이, 무지개로 빛나는 칼날, 손잡이·가드에서 튀는 불꽃 스파크 |

연출 순서: 그림 인식 → 그림이 빛나며 링이 퍼짐 → 선물 등장 → 폭죽·색종이·생일 축하 노래 → 축하 문구 → **💌 편지 열기** → 편지와 진짜 선물 힌트

선물이 나온 뒤에 쓸 수 있는 동작:
- **드래그**: 선물 돌리기
- **화면 탭**: 색종이 한 번 더
- **🔄 360° 보기**: 화면 가운데에서 손가락으로 돌려 보기(두 손가락으로 확대)
- **🔁 다시 보기**: 처음부터 다시 재생

## 인식이 잘 되게 하려면 (유리 그림)
- 유리 그림은 **어두운 단색 바탕**(검은 종이, 짙은 천) 위에 두세요. 흰 선만 보이는 상태가 가장 잘 잡힙니다.
- 화려한 무늬(나무결, 체크무늬) 위에서는 잘 안 잡힙니다.
- 인식은 일부러 느슨하게 맞췄습니다. 한 번 나온 선물은 그림을 놓쳐도 화면 앞에 계속 떠 있습니다.
- 카메라를 켠 뒤 8초 동안 준우·정우 그림이 하나도 안 잡히면 **❌ 인식 실패** 카드가 뜹니다(해결 팁 포함).
  - **🔄 다시 찾기**: 카드를 닫고 다시 8초 동안 찾습니다.
  - **🪄 마법으로 꺼내기 (준우 선물 / 정우 선물)**: 인식 없이 바로 연출을 시작합니다.
  - 기다리는 시간은 `app.js` 의 `FAIL_AFTER_MS` 로 바꿀 수 있습니다.

## 문구·편지 고치기
`config.js` 만 수정하면 됩니다(축하 문구, 표시 시간, 편지, 마지막 힌트).

## 웹으로 열기 (GitHub Pages, 카메라는 https 필요)
`.github/workflows/pages.yml` 이 들어 있어서 push 하면 자동으로 배포됩니다.
1. GitHub 저장소 → **Settings → Pages** → Source: **GitHub Actions** 선택 (처음 한 번)
2. 이 브랜치(또는 main)에 push → **Actions** 탭에서 배포가 끝나면
3. `https://<아이디>.github.io/mandu/` 를 안드로이드 크롬으로 열고 카메라를 허용

## 그림(마커) 바꾸기 / 정우 그림 추가
1. 원본 그림을 `targets/src/junwoo.png`, `targets/src/jungwoo.png` 로 넣습니다.
2. 아래 두 줄을 실행합니다.
   ```bash
   python3 tools/prepare_targets.py   # 흰 선 강화, 그림 전체/캐릭터만 2종 마커 + targets.json 생성
   npm i -g playwright && node tools/compile.js   # targets/targets.mind 생성
   ```
   한 그림마다 **그림 전체**(멀리서·비스듬히 볼 때)와 **캐릭터만**(가까이 댈 때, 2배 해상도) 두 마커를 같이 등록합니다.

## 미리보기
- `tools/preview.html`: 카메라 없이 3D 선물을 360° 돌려 보기

## 구조
```
index.html     화면(시작, 문구, 편지, 360° 보기, 마법 버튼)
app.js         AR 인식, 연출, 드래그 회전, 소리(WebAudio 합성)
models.js      코드로 만든 3D 모델(털 하프물범 필통, 스파크 검)과 애니메이션
viewer.js      360° 돌려보기 뷰어
config.js      문구·편지 설정
targets/       src/ 원본 그림, 가공된 마커 이미지, targets.json, targets.mind
tools/         마커 가공·컴파일, 미리보기
lib/           MindAR 1.2.5, three.js 0.160 (오프라인 동작용 사본)
```
